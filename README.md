## Sobre o projeto
O InovaHub é um projeto desenvolvido como parte da entrega da disciplina de desenvolvimento frontend. A ideia central é criar uma solução moderna, funcional e visualmente atraente, com foco em experiência do usuário, organização de informações e usabilidade em interfaces web.

O objetivo do projeto é demonstrar habilidades de criação de interfaces, estruturação de componentes, consumo de dados e entrega de uma aplicação com boa apresentação e navegação. A proposta pode ser adaptada ao contexto do hackathon, reunindo inovação, clareza e praticidade em um produto digital.

## Objetivo
- Desenvolver uma interface responsiva e intuitiva;
- Aplicar boas práticas de frontend;
- Priorizar uma experiência agradável para o usuário;
- Entregar uma solução funcional com foco em valor e usabilidade.
