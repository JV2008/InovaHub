
# Requisitos Não Funcionais (RNF)

## RNF01 – Responsividade
A aplicação deve ser compatível com dispositivos desktop, tablet e smartphone.

## RNF02 – Facilidade de Uso
A interface deve ser intuitiva, permitindo que novos usuários realizem as principais funções sem treinamento prévio.

## RNF03 – Desempenho
As páginas devem carregar em até 3 segundos em condições normais de uso.

## RNF04 – Disponibilidade
A aplicação deve possuir disponibilidade mínima de 95% durante sua operação.

## RNF05 – Segurança
Os dados dos usuários devem ser protegidos contra acessos não autorizados.

## RNF06 – Acessibilidade
A plataforma deve seguir boas práticas de acessibilidade digital, incluindo contraste adequado e navegação por teclado.

## RNF07 – Compatibilidade
A aplicação deve funcionar corretamente nos navegadores Google Chrome, Microsoft Edge e Mozilla Firefox.

## RNF08 – Manutenibilidade
O código deve ser organizado e modularizado para facilitar correções e futuras implementações.

## RNF09 – Escalabilidade
A arquitetura do sistema deve permitir integração futura com APIs e banco de dados sem grandes alterações estruturais.

## RNF10 – Confiabilidade
O sistema deve garantir a integridade das informações cadastradas pelos usuários, evitando perda de dados durante as operações.
